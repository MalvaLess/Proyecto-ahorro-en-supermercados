# SmartMarket — Ahorro en Supermercados

Plataforma web para comparar precios de productos entre distintas cadenas de supermercados en Uruguay, permitiendo a los usuarios encontrar las mejores ofertas y tomar decisiones de compra más inteligentes.

🌐 **App en producción:** [https://proyecto-ahorro-en-supermercados-1.onrender.com/](https://proyecto-ahorro-en-supermercados-1.onrender.com/)

---

## ¿Qué hace?

- Compara precios del mismo producto entre múltiples supermercados
- Muestra los productos con mayor descuento en tiempo real
- Permite buscar productos y filtrar por categoría
- Gestión de favoritos y listas de compras personalizadas
- Autenticación con email/contraseña y Google OAuth

## Tecnologías

| Capa | Tecnología |
|---|---|
| Frontend | React + Vite |
| Backend | Python + Flask |
| Base de datos | PostgreSQL |
| Autenticación | JWT + Google OAuth |
| Scraping | Playwright |
| Infraestructura | Render (frontend, API y DB) |
